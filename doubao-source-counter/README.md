# 豆包参考来源统计

自动识别豆包回答里的“参考资料”外链，按网站累计引用次数（每条参考来源计 1 次）。

## 安装

1. Chrome 地址栏打开 `chrome://extensions/`。
2. 打开右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本文件夹 `doubao-source-counter`。
5. 回到豆包页面并刷新一次。

## 使用与保存

- 打开豆包聊天后，点击扩展中的“扫描”，插件会自动展开折叠的参考资料。
- 每次扫描前会自动清空过去的统计，只统计当前聊天窗口中已经出现的参考资料。
- 扫描完成后会自动结束并保存结果，不会持续监听页面变化。
- 同一次扫描中的同一组参考链接只统计一次。
- 扩展图标角标显示累计引用数；点击图标可查看各网站数量。
- 每次新增统计只写入 Chrome 本地存储，不会自动下载文件。
- 需要文件时，可在弹窗中手动导出 JSON 或 CSV。
- 豆包页面右侧会显示固定统计面板，可以边聊天边查看和操作。

## 口径

- 一个参考资料链接计 1 次。
- 同一网站出现多个链接，会按链接条数累计。
- `www.`、`m.` 等常见子域会合并；抖音分享域名合并为 `douyin.com`。
