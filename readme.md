# 豆包参考来源统计

这是一个用于统计豆包回答中“参考资料”来源网站数量的 Chrome 扩展。它会自动识别豆包页面中的参考链接，按网站域名汇总引用次数，并支持本地导出 JSON / CSV 数据，方便做内容分析、资料统计和复盘。

## 项目简介

在日常使用豆包时，常常需要了解某次回答引用了哪些网站，以及不同网站被引用了多少次。这个扩展会扫描当前豆包聊天页面中的参考资料区域，自动展开折叠内容，识别每个参考链接对应的站点，并统一统计结果。

它主要适用于以下场景：

- 统计一篇豆包回答中参考了多少网站
- 统计某个站点在多次回答中的引用频次
- 导出数据用于后续整理、分析或汇总
- 在聊天过程中边看答案边观察来源分布

## 功能特点

- 自动识别豆包页面中的参考资料链接
- 按网站域名汇总引用次数
- 去重同一组参考链接，避免重复计数
- 支持当前聊天窗口统计与会话式记录
- 扩展图标显示当前累计引用数
- 可导出 JSON / CSV 文件
- 支持在豆包页面侧边展示实时统计面板

## 安装方式

1. 打开 Chrome 浏览器。
2. 访问地址栏输入 `chrome://extensions/`。
3. 打开右上角的“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择当前项目中的 `doubao-source-counter` 文件夹。
6. 打开豆包页面，刷新后即可使用。

> 该扩展只在 `https://www.doubao.com/*` 域名下生效，需确保你访问的是豆包页面。

## 使用方法

1. 打开豆包聊天页面。
2. 点击扩展图标，或页面右侧统计面板的“扫描”按钮。
3. 扩展会自动展开参考资料区域，并识别其中的链接。
4. 插件会按网站统计引用数量，并在页面侧边更新结果。
5. 如果需要导出数据，可以在弹窗中点击“导出 JSON”或“导出 CSV”。

## 统计口径

- 每条参考资料链接记为 1 次引用
- 同一网站中的多条链接会按数量累计
- 常见子域名会被规范化处理，例如 `www.`、`m.` 等会归并
- 抖音相关分享链接会统一归并到 `douyin.com`
- 同一组参考链接在一次扫描中只会统计一次，避免重复计数

## 数据说明

扩展会在 Chrome 本地存储中保留统计数据，默认会记录：

- 当前会话的来源统计
- 历史会话列表
- 每次扫描的记录明细
- 最后更新时间

导出功能会把这些数据输出为可分析的 JSON / CSV 文件。

## 适用说明

这是一个本地浏览器扩展，主要面向个人研究、内容整理和站点引用统计场景。它不会上传数据到外部服务器，数据默认保存在本地浏览器存储中。

## 备注

- 适用于 Chrome / Chromium 内核浏览器
- 需要开启“开发者模式”加载扩展
- 扫描前会清空旧统计，重新统计当前聊天页中的参考资料

## 开发说明

如果你希望继续开发或二次修改：

- `content-v2.js`：负责页面识别和扫描逻辑
- `background.js`：负责消息转发、计数更新、数据持久化和导出
- `popup.js`：负责弹窗渲染和用户交互
- `manifest.json`：控制扩展权限和页面注入范围
